Auth System

Integrate all of your favourite apps together, still keeping your data safe!

How does it work?

Auth System divides all of your app's data in different inaccessible folders, then whenever an app wants to access some of your data, you will have to allow sharing the folder to it.

How was it made?

Auth System was coded with Node JS. To guarantee the highest level of safety, the online project is not open source. Auth System, however, does have a generic public version, that you can edit to your needs.

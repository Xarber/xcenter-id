# X-Center ID icon

The original identity-card mark replaces the shield. Two offset cards provide the silhouette. The foreground uses a simple person glyph, profile lines and a mint status dot. The deep ink background uses #192750 and #081125. The indigo back card uses #526DFF, and the status dot uses #5DE9CA.

The editable master is `apps/dashboard/public/authnjs-icon.svg`, with separate groups for the background, cards, profile details and status marker. Export it at 192 and 512 pixels for PWA installation and the Expo app icon. Keep all foreground elements inside the central mask-safe region.

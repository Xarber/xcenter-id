# UADS verification baseline

The baseline uses the UADS message supplied for this assignment, identified locally as `2026-11-16-instructions` because it has no published version identifier. The project manifest and registry cover the first overhaul batch. Coverage must expand as planned surfaces become implemented.

Source checks are defined in the dashboard workflow. The validator checks structure and repository references. Requirement declarations and planning documents do not establish functional compliance. The legacy application remains outside the new workflow because the historical checkout includes sensitive account material and has no working automated test command.

The dashboard package is a mobile and web app. The planned issuer and data service require separate deployment, privacy and security evidence. Native artifacts, release automation and distribution links depend on verified implementation and an authorized release channel. The first planned deployment environment is X-Center.
